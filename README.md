# ALBINA. — сайт hair-стилиста Альбины Думбровской

Готовый адаптивный одностраничный сайт на чистых HTML, CSS и JavaScript. Не требует npm, сборки, сервера или платных библиотек. Контент подготовлен по переписке с клиентом от 15 октября 2026 года.

## Как открыть

Откройте `index.html` двойным кликом или загрузите содержимое папки на статический хостинг. Для тестирования в терминале из этой папки можно запустить `python -m http.server 8000`, затем открыть `http://localhost:8000`.

## Перед публикацией (важно)

Контакты Альбины добавлены в `config.js`: онлайн-запись DIKIDI `https://dikidi.net/2184654`, Telegram `@albinadumbrovskaya`, Instagram `@albina_well_`. Персональный портрет Альбины добавлен 24 октября 2026 года. Ссылок на Reels и адреса места работы пока нет; адрес не выдуман.

Контакты сейчас настроены в `config.js`:

```js
window.SITE_CONFIG = {
  dikidiBookingUrl: 'https://dikidi.net/2184654',
  telegram: 'albinadumbrovskaya',
  instagram: 'https://www.instagram.com/albina_well_/',
  address: '',
  reels: []
};
```

Адрес и Reels нужно заполнять только после подтверждения мастером.

Для видеоработ можно дополнительно заполнить `reels` в `config.js`, например `[{ url: 'https://www.instagram.com/reel/РЕАЛЬНЫЙ_КОД/', cover: 'assets/images/work-03.webp' }]`. Пока ссылок нет, раздел автоматически скрыт. По нажатию на карточку откроется встроенное видео Instagram (если публикация разрешает встраивание) и ссылка на оригинал. Внешние видео не загружаются до нажатия.

Кнопка «Записаться через DIKIDI» открывает подтверждённую страницу онлайн-записи. Дополнительная анкета формируется локально в браузере и копируется в буфер обмена по нажатию посетителя; автоматически в DIKIDI она не передаётся. На странице нет серверного сбора персональных данных.

В блоке «Обо мне» размещён персональный портрет мастера `assets/images/albina-portrait.webp`.

## Источники посещений сайта

Встроенная приватная статистика показывает просмотры сайта и переходы на кнопки DIKIDI, Telegram и Instagram. Отчёт доступен в CRM → **Посещения сайта** и в Telegram-боте администратора → **Посещения сайта** (за 30 дней).

Для точного различения геосервисов поставьте **разные ссылки на сайт** в каждой карточке:

- **2ГИС:** https://albinahair.swiftgifts.tg/?utm_source=2gis&utm_medium=maps&utm_campaign=business_profile
- **Яндекс Карты:** https://albinahair.swiftgifts.tg/?utm_source=yandex_maps&utm_medium=maps&utm_campaign=business_profile
- **Google Карты:** https://albinahair.swiftgifts.tg/?utm_source=google_maps&utm_medium=maps&utm_campaign=business_profile

При отсутствии UTM используется доступный `document.referrer`; приложения иногда скрывают адрес источника, поэтому часть переходов попадает в «Прямые» или «Другие». Ссылки с UTM также могут копироваться между каналами, и атрибуция не абсолютно точна.

Первичная аналитика работает без cookies, уникальных идентификаторов, IP-адресов в БД и сторонних сервисов; считается **количество загрузок страниц**, а не уникальных посетителей. Хранятся только агрегированные значения источник/тип действия/день. Необходимо отразить факт такой статистики в опубликованной политике сайта.

**Важно:** «Нажатие DIKIDI» — лишь переход по ссылке, а не подтверждённая запись. Письма DIKIDI не содержат данных об источнике перехода, поэтому автоматически привязать бронирование в DIKIDI или обычное Instagram-сообщение к конкретному посещению сайта нельзя. Когда посетитель самостоятельно копирует анкету после перехода с карт, источник добавляется в текст анкеты; клиент должен сам отправить её Альбине.

## Размещение на VPS

Для сервера **77.222.42.139** подготовлена подробная инструкция: [DEPLOY.md](DEPLOY.md). В ней рассмотрены подключение по SSH, Nginx, клонирование GitHub-репозитория, проверка портов, HTTPS и обновления.

## Деплой на GitHub Pages

1. Создайте **новый** репозиторий, например `albina-hair`.
2. Загрузите файлы **изнутри** этой папки в корень репозитория.
3. Откройте **Settings → Pages → Deploy from a branch → main → /(root)**.
4. После публикации проверьте контакты, изображения и мобильную версию. Для собственного домена настройте DNS по инструкции выбранного хостинга.
