# ALBINA. — сайт hair-стилиста Альбины Думбровской

Готовый адаптивный одностраничный сайт на чистых HTML, CSS и JavaScript. Не требует npm, сборки, сервера или платных библиотек. Контент подготовлен по переписке с клиентом от 15 октября 2026 года.

## Как открыть

Откройте `index.html` двойным кликом или загрузите содержимое папки на статический хостинг. Для тестирования в терминале из этой папки можно запустить `python -m http.server 8000`, затем открыть `http://localhost:8000`.

## Перед публикацией (важно)

Контакты Альбины получены 16 октября 2026 года и добавлены в `config.js`: WhatsApp +7 926 995-29-98, Telegram `@albinadumbrovskaya`, Instagram `@albina_well_`. Из переписки пока **нет** фотографии самой Альбины, ссылок на Reels и адреса места работы. Поэтому персональный портрет не подставлялся вместо фото клиентки, а адрес не выдуман.

Контакты сейчас настроены в `config.js`:

```js
window.SITE_CONFIG = {
  phone: '79269952998',
  telegram: 'albinadumbrovskaya',
  instagram: 'https://www.instagram.com/albina_well_/',
  address: '',
  reels: []
};
```

Номер WhatsApp приведён к международному формату с кодом России `7`. Адрес и Reels нужно заполнять только после подтверждения мастером.

Для видеоработ можно дополнительно заполнить `reels` в `config.js`, например `[{ url: 'https://www.instagram.com/reel/РЕАЛЬНЫЙ_КОД/', cover: 'assets/images/work-03.webp' }]`. Пока ссылок нет, раздел автоматически скрыт. По нажатию на карточку откроется встроенное видео Instagram (если публикация разрешает встраивание) и ссылка на оригинал. Внешние видео не загружаются до нажатия.

Кнопка в форме открывает WhatsApp с готовым текстом заявки. Сайт **не отправляет** сообщения без подтверждения клиента в мессенджере. Базы данных, сбора персональных данных и серверной отправки нет.

В блоке «Обо мне» использована одна из фотографий причесок как иллюстрация работы. Для персонального портрета мастера необходимо получить отдельное фото и согласовать замену.

## Деплой на GitHub Pages

1. Создайте **новый** репозиторий, например `albina-hair`.
2. Загрузите файлы **изнутри** этой папки в корень репозитория.
3. Откройте **Settings → Pages → Deploy from a branch → main → /(root)**.
4. После публикации проверьте контакты, изображения и мобильную версию. Для собственного домена настройте DNS по инструкции выбранного хостинга.

## Файлы
