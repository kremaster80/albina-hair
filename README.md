# ALBINA. — сайт hair-стилиста Альбины Думбровской

Готовый адаптивный одностраничный сайт на чистых HTML, CSS и JavaScript. Не требует npm, сборки, сервера или платных библиотек. Контент подготовлен по переписке с клиентом от 15 октября 2026 года.

## Как открыть

Откройте `index.html` двойным кликом или загрузите содержимое папки на статический хостинг. Для тестирования в терминале из этой папки можно запустить `python -m http.server 8000`, затем открыть `http://localhost:8000`.

## Перед публикацией (важно)

В Telegram-архиве **нет** фотографии самой Альбины, её рабочего телефона, ссылки на Instagram, ссылок на Reels и адреса места работы. Поэтому персональный портрет не подставлялся вместо фото клиентки, а контакты не выдуманы.

Откройте `config.js` и заполните реальные данные:

```js
window.SITE_CONFIG = {
  phone: '79991234567', // ПРИМЕР, замените реальным номером WhatsApp
  telegram: 'actual_username', // ПРИМЕР, при отсутствии оставить ''
  instagram: 'https://www.instagram.com/actualprofile/', // ПРИМЕР
  address: 'Город, улица, дом' // ПРИМЕР
};
```

Примеры выше **не настоящие контакты**. Если не знаете значение, оставьте пустую строку. Телефон из обсуждения предоплаты относится к исполнителю и намеренно не используется как номер мастера.

Для видеоработ можно дополнительно заполнить `reels` в `config.js`, например `[{ url: 'https://www.instagram.com/reel/РЕАЛЬНЫЙ_КОД/', cover: 'assets/images/work-03.webp' }]`. Пока ссылок нет, раздел автоматически скрыт. По нажатию на карточку откроется встроенное видео Instagram (если публикация разрешает встраивание) и ссылка на оригинал. Внешние видео не загружаются до нажатия.

После заполнения WhatsApp кнопка в форме откроет мессенджер с готовым текстом заявки. До заполнения контактов форма **не делает вид, что отправила заявку**: формирует текст и копирует его в буфер обмена. Базы данных, сбора персональных данных и серверной отправки нет.

В блоке «Обо мне» использована одна из фотографий причесок как иллюстрация работы. Для персонального портрета мастера необходимо получить отдельное фото и согласовать замену.

- Настраиваемые Instagram Reels — раздел появляется при добавлении реальных ссылок.

## Деплой на GitHub Pages

1. Создайте **новый** репозиторий, например `albina-hair`.
2. Загрузите файлы **изнутри** этой папки в корень репозитория.
3. Откройте **Settings → Pages → Deploy from a branch → main → /(root)**.
4. После публикации проверьте контакты, изображения и мобильную версию. Для собственного домена настройте DNS по инструкции выбранного хостинга.

## Файлы

- `index.html` — вся разметка и контент.
- `styles.css` — дизайн и адаптивная сетка.
- `script.js` — меню, галерея, фильтры, подготовка заявки и анимации.
- `config.js` — публичные контакты без изменения логики сайта.
- `assets/images/` — 12 оптимизированных WebP из архива.
- `assets/icons/` — favicon.

## Доступность и производительность

Промаркированы интерактивные элементы, поддерживаются клавиатура и Escape в галерее, адаптивная версия, уменьшение анимаций при соответствующей настройке ОС. Галерея грузит изображения лениво. Внешняя зависимость только Google Fonts (есть системные запасные шрифты); веб-аналитика и сторонние трекеры не добавлены.
